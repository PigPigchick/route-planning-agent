# 征询函统一排版

九类征询函共用普通 Word 版式。以用户提供的高速、军分区及矿区发函样例作为参考，提取共同的函件结构，统一字号、行距、缩进、附件列表和落款。复函 PDF 保持原件，不作为征询函红头模板。

- A4；上2.8cm、下2cm、左右2.6cm页边距。
- 黑色居中18磅标题（方正小标宋），长标题均衡换行；16磅仿宋正文，固定28磅行距，首行两字缩进。
- 发函单位及日期右对齐，联系人和复函地址左对齐。去掉源文件中的字符缩进、悬挂制表位、空白占位和黄色编辑标记。
- 不增加红头、红线或额外页眉。参数表保留各档跨越数据，表头跨页重复。
- 函件正文不附加待补资料、演示说明或复核状态提示。草稿仅在单份 Word、批量 ZIP 及包内 Word 文件名中标注“草稿_”；模拟测试标记放在文件名，复核及资料检查结果保存在独立记录中。
- 单份 Word 和 ZIP 共用 `backend/word_layout.py`，已有正文重新导出即可，不需再次调用模型。

`letter-plain.docx` 为清空历史内容的样式底稿；运行无需准备原始参考。接收设备缺少参考字体时，Word/WPS可能使用替代字体，字形和分页会略有差异。

验证：`npm run test:word-layout`。样张及渲染核对记录位于 `outputs/征询函统一格式_2026-10-30/`。
