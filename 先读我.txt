路径规划智能体 / 输电设计工作台

1. 克隆仓库或下载 ZIP 完整解压，进入包含 package.json 的项目根目录。
2. 阅读“新设备安装与启动说明.md”。
3. 安装 Node.js 22+、Python 3.10+；创建 .venv 并安装 requirements.txt。
4. 运行 npm run check:setup 检查环境。
5. 用两个终端分别运行 npm run dev:backend 和 npm run dev:frontend。
6. 打开 http://127.0.0.1:5173/#letters 。
7. 在右上角“设置 → 大模型配置”填写自己的 API Key。地址、模型和参数可参考 .env.example。
8. 阅读 README.md、LETTERS.md 和“使用文档与样例”中的操作说明。

仓库包含完整前后端源码、接口文档、测试和依赖清单。首次安装 Python 依赖需联网。
前后端分离运行，不使用 .command 启动文件，不依赖原电脑路径或 Codex 应用。
API Key、个人输入、实际工程附件和运行历史未上传。新设备请重新配置并导入业务资料。
